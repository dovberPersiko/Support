Open source & LGPL

Last updated: 9 November 2026 · applies to JCalendar for iOS, version 2.0

JCalendar uses a library that is licensed under the GNU Lesser General Public License, version 2.1 (LGPL-2.1). This page gives the notices, where to get the source code, and how to replace the library with your own build.

The LGPL library

KosherSwift 1.10.8

What it does
A Swift port of KosherJava Zmanim. JCalendar uses it for holidays, parsha, Daf Yomi and zmanim.
License
GNU Lesser General Public License 2.1. Full text: gnu.org, and inside the app under Settings → About.
Copyright
Eliyahu Hershfeld (KosherJava, the original library), and the authors of KosherSwift.
Source code
github.com/Elyahu41/KosherSwift, tag 1.10.8, commit 73f9daf16c9abb6191c7b257fb258515571bd7e9. (The repository also has an older tag 2.0.0 that does not contain this code. Use the commit above.)
Our changes
None. The library is included unmodified.

The original Java library, KosherJava Zmanim, is at github.com/KosherJava/zmanim.

How the app complies

KosherSwift is built as its own dynamic framework, KosherSwift.framework, and is embedded in the app at JCalendar.app/Frameworks/. It is not statically linked into the app. This lets you replace it with a modified version, as the LGPL requires.

Get the source code of the app

The app's own source code is not published on the web. As required by LGPL-2.1 section 6, we offer, to anyone who has a copy of the app, the source code of the app and the build files needed to rebuild it with a modified version of the library. Request it by email:

dober.p@gmail.com

Subject: JCalendar source code request. We send the source (the Xcode project configuration, the vendored library and the app code that calls it) within a reasonable time, for the cost of a copy or free of charge. This offer is valid for at least three years from the date of the release that includes the library.

Replace the library with your own build

With the source code from the request above:

  1. Edit the library sources in iosApp/ThirdParty/KosherSwift/Sources/KosherSwift, or replace that folder with your own fork. Keep the module name KosherSwift and the public API that the app calls.
  2. Generate the project and build: 
    cd iosApp
xcodegen generate
xcodebuild -project iosApp.xcodeproj -scheme iosApp \
  -configuration Debug \
  -destination 'platform=iOS Simulator,name=iPhone 17' build
  3. To avoid rebuilding the whole app, build only the KosherSwift framework target and copy the result over iosApp.app/Frameworks/KosherSwift.framework, then sign the app with your own identity. An app installed on a physical device must be signed.
